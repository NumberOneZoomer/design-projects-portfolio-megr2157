## Project Description

Our original goal was to create a fan that cooled objects off when they are in certain range of an ultrasonic sensor. Our MVP was to have a fan turn on when they are within a certain range of an object, and our stretch goal was to have it on a servo and track an object or find the closest object to cool off.
